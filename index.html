A fixed-size matrix can remember many things — until it can't.
Watch a linear-attention memory fill up in real time.

The claim this teaches: a linear-attention layer's recurrent state is an associative memory built by summing outer products of keys and values. Writing a new pair costs a fixed amount of work and never grows the memory's size — but retrieval quality degrades through interference once the number of stored pairs approaches the memory's dimension. Everything below is computed live in your browser as you interact — no training, no precomputed results, pure linear algebra.
